# Handoff — Potting Bench (theapp)

Written 4 Sep 2026. Read this before touching anything.

## What this project is

One file. `index.html` is about 26,000 lines and holds the entire
application: a single `<style>` region (six blocks), the markup for every
view as `<section id="view-…">`, and one enormous classic `<script>`. There
is no build step and no framework. `sw.js` is a service worker; everything
else in the tree is tooling.

Serve it with the existing config: `.claude/launch.json` defines a `theapp`
server on port 8955 (`python3 -m http.server`). Do **not** delete `.claude/`
— it holds that config plus local settings.

## The rule that matters most

**Several Claude sessions edit `index.html` at the same time.** This is
normal here, not an accident. Simon keeps two or three open against the same
worktree, and a Munder Difflin agent floor can add more.

Consequences, all learned the hard way:

- **Never use whole-file writes on `index.html`.** Use string-anchored edits.
  They either apply correctly to a shifted file or fail loudly; a
  line-addressed write silently destroys whatever a peer saved seconds ago.
- **Never run a bare `git add index.html`.** It stages whatever every other
  session happens to have in the file at that instant. Stage your own hunks,
  then check `git diff --cached` before committing.
- **Re-parse the staged blob, not the working tree.** `git show :index.html`,
  extract the largest `<script>` block, `node --check` it. Splitting hunks can
  stage a file that is valid per-hunk and broken as a whole.
- **Append at the end of a block** rather than inserting mid-file. New CSS at
  the end of a `<style>` block, new JS at the end of the script.

## What happened in this session

**The plant library went from 158 plants to 1,074.** Twenty-three genus
batches were generated by a Munder Difflin agent floor, validated, and merged.

**A toxicity gate was added to `tools/merge_plants.py`.** This is the
important one. The spec had always said toxicity was the one field where a
guess is unacceptable — and a run of nineteen batches still came back with
maidenhair fern, bird's nest fern, parlour palm, sundew, butterwort and
Sarracenia all marked toxic to cats and dogs. All are non-toxic. The batches
also contradicted each other, which is what gave it away.

So `TOXICITY` in that script now holds the settled ASPCA answers keyed by
genus and common name, and a record contradicting one is a hard error —
nothing merges. It refuses in both directions; a toxic plant marked safe
fails as hard as a safe plant marked toxic. A plant absent from the table is
**not** thereby cleared, only uncovered. Never add a guess to that table;
everything in it becomes unarguable.

**The parking lot was fixed on phones** (commit `5aaba19`). `.wb-parking` and
`.wb-quick` capped at three rows / 132px each, which is a desktop cap. On a
375px phone the chrome above them already costs 305px. Now two rows under
640px wide, one row under 520px tall.

## The plant data pipeline

```
tools/plant-data-handoff.md    the spec, with a {{GENUS}} placeholder
tools/batches/<genus>.json     one file per genus — the source of truth
tools/merge_plants.py          validates and merges
tools/existing-names.txt       generated by --names
```

- `python3 tools/merge_plants.py tools/batches/x.json --check` validates only.
- `python3 tools/merge_plants.py tools/batches/*.json` merges the lot. It is
  idempotent: it rewrites one `GENERATED` block whole from the batch files
  every run, so re-running never double-adds.
- `index.html` is the **output**. The batch files are the input. The
  `SPECIES` literal still reads 158; the other 916 are injected at load by
  the generated block. A count of 158 in the source is not a bug.

## Munder Difflin (the agent harness)

Installed this session at `/Applications/Munder Difflin.app`. Hive lives at
`~/HarnessAgents/hive/` — `registry.json` for the fleet, `spawn-requests/`
for pending workers, `PROTOCOL.md` and `COMMANDS.md` for the rules.

Things worth knowing:

- **Workers do not self-start.** A spawned agent sits idle at 0% context
  until it receives a prompt. A standing goal alone does not trigger it.
- **Autonomous spawning is off by default** (Settings → Autonomy & Budgets).
  Requests then sit in `spawn-requests/` unpicked, neither failed nor
  deleted, which looks like a bug and is not.
- **Git isolation (own worktree)** is per-agent, on the Workspace step. Turn
  it **on** for code work on `index.html` — each agent gets its own checkout.
  Turn it **off** for the plant work, because the spec file is untracked and
  would not exist in a fresh worktree.
- Workers are briefed never to touch `index.html`. Keep it that way.

## Gotchas that will waste your time

- A **GateGuard hook** intercepts the first Bash command and every file
  write, demanding a short "facts" preamble. Answer it and retry the same
  command; it is not a permission denial.
- Port **8955** is often already held by a peer session's server. Navigate to
  it rather than starting a second one.
- A console 404 for **`/data/state.json`** is pre-existing and harmless.
- `.claude/` and `qa-home.yml` at the repo root belong to other sessions.
  Leave them alone.

## House style

Commit messages here are prose, sentence case, no prefix, and explain the
reasoning at length — the subject line states the user-visible outcome.
Student- and user-facing strings are British English, plain and declarative,
never an exclamation mark.

Simon wants the verdict in the first line of any report. The explanation
goes underneath it, and the long reasoning belongs in the commit message.
